# Presenting and recording SkillPrompt

No video was supplied. The published demo is a recorded text conversation with an interactive walkthrough. A future screen recording should be labeled as either a walkthrough of that record or a fresh live run.

## Short presenter script (about two minutes)

“SkillPrompt is a personal agent in HokieAI that helps refine research requests using curated academic methods. The user can inspect proposed changes, accept selected parts, and decide when the prompt is ready.

“The implementation is native agent instructions, one uploaded knowledge TXT, and the platform model shown in these screenshots. The collection has 16 cards in seven categories, adapted with AI assistance from four open-source repositories. We contributed selection, adaptation, matching terms, source documentation, and the user-control workflow. The upstream authors contributed the research methods.

“In the first turn, a researcher plans to upload five papers about generative AI for research writing. They want a roughly 500-word comparison and ask only to refine the prompt. SkillPrompt selects SK04 and SK08 and proposes a detailed request.

“In the second turn, the researcher keeps thematic comparison, the five-paper boundary, and traceable references. They remove strict word and paragraph limits, reduce evaluation detail, and ask for labels after upload. The agent revises accordingly.

“In the final turn, the researcher accepts. The agent returns a prompt without another confirmation or a literature review. The copy button gives the recorded final text.

“This record also exposes limitations: the first SK08 quotation is not fully exact, the later explanation still overattributes plain-language tone to a card, and the paper-label syntax is an implementation choice. Our annotations are separate from the original messages. No papers or review execution are part of the record. The site shares the documentation and configuration; a cross-user link to the native agent remains unverified.”
