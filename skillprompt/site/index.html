The problem & the approach

Useful structure. Room for judgment.

Research requests often leave the evidence boundary, comparison structure, or desired output implicit. A generic rewrite can also add constraints the researcher never asked for.

SkillPrompt connects a request to a small library of research methods and makes the proposed changes visible. The user can retain selected additions and remove others before accepting a final prompt.

The configured workflow

  1. Understand the request and identify relevant categories.
  2. Choose one primary card and up to two supporting cards.
  3. Propose a prompt and explain the meaningful changes.
  4. Accept selective feedback and revise.
  5. Finalize on acceptance, or preserve the original on rejection.

The demo shows proposal → selective revision → acceptance. Rejection of all changes, missing-library fallback, and rematching after a changed task are configured behaviors, not demonstrated outcomes.

Reproduction guide

Recreate SkillPrompt in HokieAI.

The public walkthrough is available to everyone. Recreating the agent requires appropriate HokieAI access. A working public or cross-user SkillPrompt link has not been verified.

  1. Open HokieAI and create a Personal Agent. Name it SkillPrompt. The official HokieAI overview describes personal agents. The portal link below does not open this particular agent.
  2. Paste the supplied English Specific instructions. Use the complete, unchanged instructions TXT. The original Short Description was blank; leave it blank to match the record. The Platform tab was not collected, so its contents cannot be reproduced from this handoff.
  3. Upload only the knowledge TXT as the knowledge source. Use SkillPrompt_Academic_Knowledge_v1.txt. Keep the full sources and license notices alongside any redistributed copy; they are documentation, not an additional knowledge upload.
  4. Match the recorded model and capabilities. Select OpenAI (gpt-5) if available; disclose any substitute and the date. Enable Add Files & Images. Disable Image Creation, Search the Internet, and Generate Artifacts. Save the agent.
  5. Run the three guided inputs in order. Start a fresh chat, send the user inputs from the transcript, and record the actual responses. Do not upload five papers for this prompt-refinement scenario. A fresh run may differ from the recorded outputs.

Curation & attribution

A small library, with traceable origins.

The September 22 collection was assembled with AI assistance from four community repositories. The contribution is selection and adaptation: shorter method cards, a seven-category taxonomy, 16 local IDs, bilingual matching terms, source and license documentation, agent instructions, and an iterative workflow that keeps users in control.

Upstream authors contributed the research methods. This project does not claim to have invented those methods or trained a model. Promotional defaults, unrelated installation steps, and arbitrary output quotas were omitted from the adaptations.
