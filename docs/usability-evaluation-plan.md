# Student guide usability evaluation plan

## Goal

Evaluate whether VT students can reach a defensible recommendation, understand why tools were excluded, recognize the institutional-account boundary, and stop on prohibited data.

## Core tasks

1. Choose each of the eight task types and explain the resulting primary recommendation.
2. Require user-provided sources and a file upload; identify which tools fail the capability stage.
3. Select export-controlled data or CUI and confirm that no AI recommendation appears.
4. Compare results with and without an ARC account.
5. Find the direct access link, account requirement, limits, prohibited data, source, and verification date on a result card.
6. Complete all paths on a phone-sized viewport and with keyboard-only navigation.

Use only synthetic or public example data.

## Success measures

| Measure | Target |
| --- | --- |
| Recommender completion without help | at least 90% |
| Correct explanation of filter order | at least 85% |
| CUI/export-control stop recognition | 100% |
| Correct institutional-account identification | at least 90% |
| ARC condition understood | at least 90% |
| Critical accessibility barriers | 0 |

Evaluate at 320 CSS pixels, 200% and 400% zoom, keyboard only, visible focus, screen-reader landmarks/names/states, contrast, and reduced motion. Automated checks support but do not replace testing with assistive technology users.
